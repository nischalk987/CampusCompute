# CampusCompute — Evidence Gallery

This directory contains the screenshot evidence for the **CampusCompute: Intelligent Job Scheduling and Resource Management** mini-project.

The images below are embedded directly from this `evidence/` directory. They are arranged by evidence ID and capture sequence. Filenames are preserved exactly as they exist in the repository.

## Evidence overview

| Evidence ID | Area demonstrated |
|---|---|
| S01–S03 | Environment, compiler/build tools, and project source files |
| S04–S05 | Clean build and command-line interface |
| S06–S09 | CPU scheduling: job details, FCFS, Round Robin, Priority, and policy comparison |
| S10–S11 | Producer-consumer logging and thread synchronization |
| S12–S13 | Shared-memory IPC, semaphore coordination, and cleanup |
| S14–S15 | Banker's algorithm: safe and unsafe states |
| S16–S18 | Worker process lifecycle, simulated worker failure, and resource limits |
| S19–S20 | Invalid input handling and cleanup verification |
| S21 | Integrated execution |
| S22 | Generated activity logs |
| S23 | Final source files |
| S24 | Submission archive and verification |
